Сборник задач по дифференциальным уравнениям

§1. Изоклины. Составление дифференциального уравнения семейства кривых
Задачи:

📖 Теоретическая справка

1. Изоклины. Решение уравнения $y' = f(x,y)$, проходящее через точку $(x,y)$, должно иметь в этой точке производную $y'$, равную $f(x,y)$. Геометрическое место точек плоскости, в которых наклон касательных к решениям уравнения $y' = f(x,y)$ один и тот же, называется изоклиной. Уравнение изоклины: $f(x,y) = k$, где $k$ — постоянная.

2. Составление ДУ семейства кривых. Чтобы построить дифференциальное уравнение, которому удовлетворяют кривые семейства $\varphi(x, y, C_1, \ldots, C_n) = 0$, надо продифференцировать равенство $n$ раз, считая $y$ функцией от $x$, а затем из полученных уравнений и исходного исключить произвольные постоянные $C_1, \ldots, C_n$.

3. Изогональные траектории. Линии, пересекающие все кривые данного семейства под одним и тем же углом $\varphi$, называются изогональными траекториями. Если $y' = f(x,y)$ — уравнение семейства, а $y' = f_1(x,y)$ — уравнение траекторий, то $\operatorname{tg}\alpha = f(x,y)$, $\operatorname{tg}\beta = f_1(x,y)$, где $\beta = \alpha \pm \varphi$. При $\varphi = 90°$ получаются ортогональные траектории.

Задачи 1–14. Изоклины: начертить приближённые решения
С помощью изоклин начертить (приближенно) решения данных уравнений.
1
$y' = y - x^2$
▼

Решение

Шаг 1. Находим изоклины

Изоклины — это кривые, на которых $y' = k = \text{const}$. Приравниваем: $y - x^2 = k$, то есть $y = x^2 + k$.

Изоклины — это параболы $y = x^2 + k$, сдвинутые по вертикали.

Шаг 2. Строим изоклины для разных $k$

При $k = 0$: $y = x^2$ (нулевая изоклина — на ней касательные горизонтальны).

При $k = 1$: $y = x^2 + 1$ (наклон касательных $= 1$, т.е. $45°$).

При $k = -1$: $y = x^2 - 1$ (наклон $= -1$, т.е. $-45°$).

При $k = 2$: $y = x^2 + 2$ и т.д.

Шаг 3. Рисуем поле направлений и интегральные кривые

На каждой изоклине $y = x^2 + k$ проводим чёрточки с наклоном $k$. Затем проводим кривые, касающиеся этих чёрточек — это и есть приближённые решения.

Интегральные кривые «стекают» к параболе $y = x^2$ снизу и «убегают» вверх от неё сверху.

2
$2(y + y') = x + 3$
▼

Решение

Шаг 1. Выражаем $y'$

$2y + 2y' = x + 3 \implies y' = \dfrac{x + 3 - 2y}{2} = \dfrac{x - 2y + 3}{2}$.

Шаг 2. Находим изоклины

$\dfrac{x - 2y + 3}{2} = k \implies x - 2y + 3 = 2k \implies y = \dfrac{x + 3 - 2k}{2}$.

Изоклины — семейство прямых $y = \frac{1}{2}x + \frac{3 - 2k}{2}$ с наклоном $\frac{1}{2}$.

Шаг 3. Строим

Все изоклины — параллельные прямые с наклоном $1/2$. На каждой из них чёрточки имеют наклон $k$. Проводим интегральные кривые, касающиеся чёрточек.

3
$y' = \dfrac{x^2 + y^2}{2} - 1$
▼

Решение

Шаг 1. Находим изоклины

$\dfrac{x^2 + y^2}{2} - 1 = k \implies x^2 + y^2 = 2(k + 1)$.

Изоклины — окружности с центром в начале координат и радиусом $r = \sqrt{2(k+1)}$ (при $k > -1$).

Шаг 2. Строим

При $k = 0$: $x^2 + y^2 = 2$, $r = \sqrt{2}$ — нулевая изоклина.

При $k = 1$: $x^2 + y^2 = 4$, $r = 2$.

При $k = -1$: точка $(0, 0)$.

Внутри окружности $x^2 + y^2 = 2$ наклоны отрицательны, вне — положительны.

4
$(y^2 + 1)y' = y - x$
▼

Решение

Шаг 1. Выражаем $y'$

$y' = \dfrac{y - x}{y^2 + 1}$.

Шаг 2. Находим изоклины

$\dfrac{y - x}{y^2 + 1} = k \implies y - x = k(y^2 + 1) \implies x = y - k(y^2 + 1)$.

При $k = 0$: $x = y$ — прямая (нулевая изоклина).

При других $k$: параболы с осью, параллельной $Ox$.

5
$yy' + x = 0$
▼

Решение

Шаг 1. Выражаем $y'$

$y' = -\dfrac{x}{y}$ (при $y \ne 0$).

Шаг 2. Находим изоклины

$-\dfrac{x}{y} = k \implies y = -\dfrac{x}{k}$ (при $k \ne 0$).

Изоклины — прямые, проходящие через начало координат. При $k = 0$: ось $Oy$ ($x = 0$).

Шаг 3. Решения

Уравнение $yy' + x = 0$ переписывается как $y\,dy = -x\,dx$, откуда $\dfrac{y^2}{2} = -\dfrac{x^2}{2} + C$, т.е. $x^2 + y^2 = C$.

Интегральные кривые — окружности с центром в начале координат.

6
$xy' = 2y$
▼

Решение

Шаг 1. Выражаем $y'$

$y' = \dfrac{2y}{x}$ (при $x \ne 0$).

Шаг 2. Находим изоклины

$\dfrac{2y}{x} = k \implies y = \dfrac{kx}{2}$.

Изоклины — прямые через начало координат.

Шаг 3. Решаем уравнение

$\dfrac{dy}{y} = \dfrac{2\,dx}{x} \implies \ln|y| = 2\ln|x| + C_1 \implies y = Cx^2$.

Интегральные кривые — параболы $y = Cx^2$.

7
$xy' + y = 0$
▼

Решение

Шаг 1. Выражаем $y'$

$y' = -\dfrac{y}{x}$ (при $x \ne 0$).

Шаг 2. Изоклины

$-\dfrac{y}{x} = k \implies y = -kx$ — прямые через начало координат.

Шаг 3. Решаем

$\dfrac{dy}{y} = -\dfrac{dx}{x} \implies \ln|y| = -\ln|x| + C_1 \implies xy = C$.

Интегральные кривые — гиперболы $xy = C$.

8
$y' + y = (x - y')^3$
▼

Решение

Шаг 1. Изоклины

Полагая $y' = k$: $k + y = (x - k)^3$, т.е. $y = (x - k)^3 - k$.

Для каждого $k$ — кубическая парабола, сдвинутая на $k$ вправо и $k$ вниз.

Шаг 2. Построение

При $k = 0$: $y = x^3$ — нулевая изоклина. На ней проводим горизонтальные чёрточки.

При $k = 1$: $y = (x - 1)^3 - 1$. Чёрточки наклонены под углом $45°$.

Строим поле направлений и проводим интегральные кривые.

9
$y' = x - e^y$
▼

Решение

Шаг 1. Изоклины

$x - e^y = k \implies x = k + e^y$.

Для каждого $k$ это кривая — сдвиг экспоненты $x = e^y$ на $k$ вправо.

Шаг 2. Нулевая изоклина

При $k = 0$: $x = e^y$, т.е. $y = \ln x$ — на этой кривой касательные горизонтальны.

10
$y(y' + x) = 1$
▼

Решение

Шаг 1. Выражаем $y'$

$yy' + xy = 1 \implies y' = \dfrac{1}{y} - x = \dfrac{1 - xy}{y}$.

Шаг 2. Изоклины

$\dfrac{1 - xy}{y} = k \implies 1 - xy = ky \implies y = \dfrac{1}{x + k}$.

Изоклины — гиперболы $y = \frac{1}{x+k}$.

11
$y' = \dfrac{y - 3x}{x + 3y}$
▼

Решение

Шаг 1. Изоклины

$\dfrac{y - 3x}{x + 3y} = k \implies y - 3x = k(x + 3y) \implies y(1 - 3k) = x(3 + k)$.

$y = \dfrac{3 + k}{1 - 3k}\,x$ — прямые через начало координат (однородное уравнение).

12
$y' = \dfrac{y}{x + y}$
▼

Решение

Шаг 1. Изоклины

$\dfrac{y}{x + y} = k \implies y = k(x + y) = kx + ky \implies y(1 - k) = kx$.

$y = \dfrac{k}{1 - k}\,x$ (при $k \ne 1$) — прямые через начало координат.

При $k = 0$: ось $Ox$. При $k = 1/2$: $y = x$.

13
$x^2 + y^2 y' = 1$
▼

Решение

Шаг 1. Выражаем $y'$

$y' = \dfrac{1 - x^2}{y^2}$ (при $y \ne 0$).

Шаг 2. Изоклины

$\dfrac{1 - x^2}{y^2} = k \implies y^2 = \dfrac{1 - x^2}{k}$ (при $k \ne 0$).

При $k > 0$ и $|x| < 1$ — эллипсы. При $k = 0$: $x = \pm 1$ — вертикальные прямые.

14
$(x^2 + y^2)y' = 4x$
▼

Решение

Шаг 1. Выражаем $y'$

$y' = \dfrac{4x}{x^2 + y^2}$.

Шаг 2. Изоклины

$\dfrac{4x}{x^2 + y^2} = k \implies x^2 + y^2 = \dfrac{4x}{k} \implies \left(x - \dfrac{2}{k}\right)^2 + y^2 = \dfrac{4}{k^2}$.

Изоклины — окружности с центром $\left(\frac{2}{k}, 0\right)$ и радиусом $\frac{2}{|k|}$, проходящие через начало координат.

Задачи 15–16. Геометрические места точек
Экстремумы и точки перегиба решений.
15
Написать уравнение ГМТ точек максимума или минимума решений уравнения $y' = f(x,y)$. Как отличить max от min?
▼

Решение

Ответ: $f(x,y) = 0$; $f'_x < 0$ (max), $f'_x > 0$ (min).

Объяснение

В точке экстремума $y' = 0$, т.е. $f(x,y) = 0$ — это и есть искомое ГМТ (нулевая изоклина).

Для отличия максимума от минимума исследуем $y'' = \dfrac{d}{dx}f(x,y) = f'_x + f'_y \cdot y'$.

В точке экстремума $y' = 0$, поэтому $y'' = f'_x$.

Если $f'_x < 0$, то $y'' < 0$ — максимум. Если $f'_x > 0$, то $y'' > 0$ — минимум.

16
Написать уравнение ГМТ точек перегиба графиков решений уравнений
▼

Решение

а) $y' = y - x^2$

Ответ: $y = x^2 + 2x$

$y'' = y' - 2x = (y - x^2) - 2x$. Точки перегиба: $y'' = 0 \implies y = x^2 + 2x$.

б) $y' = x - e^y$

Ответ: $x = 2\operatorname{ch} y$; б) $x = 2\cosh y$

$y'' = 1 - e^y \cdot y' = 1 - e^y(x - e^y) = 1 - xe^y + e^{2y}$. Приравниваем к нулю.

в) $x^2 + y^2 y' = 1$

Ответ: $xy^3 = -(1-x^2)^2$; $y = 0$

$y' = \frac{1-x^2}{y^2}$. Дифференцируем: $y'' = \frac{-2xy^2 - 2y y'(1-x^2)}{y^4}$. Приравниваем числитель к нулю.

г) $y' = f(x,y)$

Ответ: $f'_x + f \cdot f'_y = 0$

$y'' = f'_x + f'_y \cdot y' = f'_x + f \cdot f'_y = 0$.

Задачи 17–29. Составление ДУ семейства кривых
Составить дифференциальные уравнения данных семейств линий.
17
$y = e^{Cx}$
▼

Решение

Ответ: $y = e^{xy'/y}$

Шаг 1. Дифференцируем

$y' = Ce^{Cx} = Cy$.

Шаг 2. Исключаем $C$

Из $y' = Cy$ находим $C = \dfrac{y'}{y}$. Подставляем в исходное: $y = e^{(y'/y) \cdot x}$.

18
$y = (x - C)^3$
▼

Решение

Ответ: $y' = 3y^{2/3}$

Шаг 1. Дифференцируем

$y' = 3(x - C)^2$.

Шаг 2. Исключаем $C$

Из исходного: $(x - C) = y^{1/3}$, тогда $(x-C)^2 = y^{2/3}$.

Подставляем: $y' = 3y^{2/3}$.

19
$y = Cx^3$
▼

Решение

Ответ: $xy' = 3y$

Шаг 1. Дифференцируем

$y' = 3Cx^2$.

Шаг 2. Исключаем $C$

$C = \dfrac{y}{x^3}$. Подставляем: $y' = 3 \cdot \dfrac{y}{x^3} \cdot x^2 = \dfrac{3y}{x}$.

Итого: $xy' = 3y$.

20
$y = \sin(x + C)$
▼

Решение

Ответ: $y^2 + y'^2 = 1$

Шаг 1. Дифференцируем

$y' = \cos(x + C)$.

Шаг 2. Исключаем $C$

$y^2 + y'^2 = \sin^2(x+C) + \cos^2(x+C) = 1$.

21
$x^2 + Cy^2 = 2y$
▼

Решение

Ответ: $x^2y' - xy = yy'$

Шаг 1. Выражаем $C$

$C = \dfrac{2y - x^2}{y^2}$.

Шаг 2. Дифференцируем исходное

$2x + 2Cyy' = 2y' \implies 2x + 2y' \cdot \dfrac{2y - x^2}{y^2} \cdot y = 2y'$.

$2x + \dfrac{2y'(2y - x^2)}{y} = 2y'$.

Умножаем на $y$: $2xy + 2y'(2y - x^2) = 2yy'$.

$2xy + 4yy' - 2x^2y' = 2yy' \implies 2xy + 2yy' = 2x^2y'$.

$x^2y' - xy = yy'$.

22
$y^2 + Cx = x^3$
▼

Решение

Ответ: $2xyy' - y^2 = 2x^3$

Шаг 1. Дифференцируем

$2yy' + C = 3x^2$.

Шаг 2. Исключаем $C$

Из исходного: $C = \dfrac{x^3 - y^2}{x}$. Подставляем:

$2yy' + \dfrac{x^3 - y^2}{x} = 3x^2$.

Умножаем на $x$: $2xyy' + x^3 - y^2 = 3x^3 \implies 2xyy' - y^2 = 2x^3$.

23
$y = C(x - C)^2$
▼

Решение

Ответ: $y'^3 = 4y(xy' - 2y)$

Шаг 1. Дифференцируем

$y' = 2C(x - C)$.

Шаг 2. Исключаем $C$

Из $y = C(x-C)^2$ и $y' = 2C(x-C)$: $\dfrac{y'}{y} = \dfrac{2}{x - C} \implies x - C = \dfrac{2y}{y'}$.

Тогда $C = x - \dfrac{2y}{y'}$. Подставляя в $y' = 2C(x-C)$:

$y' = 2\left(x - \dfrac{2y}{y'}\right) \cdot \dfrac{2y}{y'} = \dfrac{4y}{y'}\left(x - \dfrac{2y}{y'}\right) = \dfrac{4y(xy' - 2y)}{y'^2}$.

$y'^3 = 4y(xy' - 2y)$.

24
$Cy = \sin Cx$
▼

Решение

Ответ: $y' = \cos\dfrac{x\sqrt{1-y'^2}}{y}$

Шаг 1. Дифференцируем

$Cy' = C\cos(Cx)$, т.е. $y' = \cos(Cx)$.

Шаг 2. Исключаем $C$

Из $y' = \cos(Cx)$: $Cx = \arccos y'$, т.е. $C = \frac{\arccos y'}{x}$.

Из $Cy = \sin(Cx)$: $\sin(Cx) = Cy$, $\sin(\arccos y') = Cy$, $\sqrt{1 - y'^2} = Cy$.

$C = \frac{\sqrt{1-y'^2}}{y}$. Итого: $y' = \cos\frac{x\sqrt{1-y'^2}}{y}$.

25
$y = ax^2 + be^x$ (два параметра $a, b$)
▼

Решение

Ответ: $x(x-2)y'' - (x^2 - 2)y' + 2(x-1)y = 0$

Шаг 1. Дифференцируем дважды

$y' = 2ax + be^x$, $y'' = 2a + be^x$.

Шаг 2. Исключаем $a$ и $b$

Из $y'' = 2a + be^x$: $be^x = y'' - 2a$. Из $y' = 2ax + be^x$: $be^x = y' - 2ax$, следовательно $y'' - 2a = y' - 2ax$, $2a(x - 1) = y' - y''$, $a = \frac{y' - y''}{2(x-1)}$.

$b = (y'' - 2a)e^{-x}$. Подставляем в $y = ax^2 + be^x$ и упрощаем, получаем указанный ответ.

26
$(x-a)^2 + by^2 = 1$ (два параметра $a, b$)
▼

Решение

Ответ: $(yy'' + y'^2)^2 = -y^3 y''$

Шаг 1. Дифференцируем дважды

$2(x-a) + 2byy' = 0 \implies (x-a) + byy' = 0$. (I)

$1 + b(y'^2 + yy'') = 0$. (II)

Шаг 2. Исключаем $a$ и $b$

Из (II): $b = \dfrac{-1}{y'^2 + yy''}$.

Из (I): $x - a = -byy' = \dfrac{yy'}{y'^2 + yy''} $.

Дифференцируем (I) ещё раз и подставляем, получаем ответ.

27
$\ln y = ax + by$ (два параметра $a, b$)
▼

Решение

Ответ: $y''y^2(\ln y - 1) = y'^2(xy' - y)$

Шаг 1. Дифференцируем

$\dfrac{y'}{y} = a + by'$. (I)

Дифференцируем ещё: $\dfrac{y''y - y'^2}{y^2} = by''$. (II)

Шаг 2. Исключаем $a$ и $b$

Из (II): $b = \dfrac{y''y - y'^2}{y^2 y''}$. Из (I): $a = \frac{y'}{y} - by'$. Подставляем в исходное уравнение $\ln y = ax + by$.

28
$y = ax^3 + bx^2 + cx$ (три параметра)
▼

Решение

Ответ: $x^3y''' - 3x^2y'' + 6xy' - 6y = 0$

Шаг 1. Дифференцируем трижды

$y' = 3ax^2 + 2bx + c$, $y'' = 6ax + 2b$, $y''' = 6a$.

Шаг 2. Выражаем параметры

$a = \frac{y'''}{6}$, $b = \frac{y'' - 6ax}{2} = \frac{y'' - xy'''}{2}$, $c = y' - 3ax^2 - 2bx$.

Подставляем в $y = ax^3 + bx^2 + cx$ и упрощаем.

29
$x = ay^2 + by + c$ (три параметра)
▼

Решение

Ответ: $y'''y' = 3y''^2$

Шаг 1. Дифференцируем

$1 = (2ay + b)y'$. Дифференцируем: $0 = 2ay'^2 + (2ay+b)y''$.

Дифференцируем ещё раз: $0 = 6ay'y'' + (2ay+b)y'''$.

Шаг 2. Исключаем параметры

Из первого: $(2ay+b) = \frac{1}{y'}$. Из второго: $2a = \frac{-y''}{y'^3}$.

Подставляем в третье: $6 \cdot \frac{-y''}{2y'^3} \cdot y' \cdot y'' + \frac{1}{y'} \cdot y''' = 0$.

$\frac{-3y''^2}{y'^2} + \frac{y'''}{y'} = 0 \implies y'''y' = 3y''^2$.

Задачи 30–34. Составление ДУ по геометрическим свойствам
Составить ДУ кривых с заданными геометрическими свойствами.
30
Составить ДУ окружностей радиуса 1, центры которых лежат на прямой $y = 2x$.
▼

Решение

Ответ: $(y - 2x)^2(y'^2 + 1)^2 = (2y' + 1)^2 \cdot (y'^2 + 1)$... упрощается до $(y-2x)^2(1+y'^2) = (1+2y')^2$

Решение

Центры: $(a, 2a)$. Уравнение семейства: $(x - a)^2 + (y - 2a)^2 = 1$.

Дифференцируем: $2(x-a) + 2(y - 2a)y' = 0 \implies x - a = -(y - 2a)y'$.

$a = \frac{x + yy'}{1 + 2y'}$. Подставляем в исходное и получаем ДУ без параметра $a$.

31
Составить ДУ парабол с осью, параллельной $Oy$, и касающихся одновременно прямых $y = 0$ и $y = x$.
▼

Решение

Подход

Парабола с осью параллельной $Oy$: $y = A(x-h)^2 + k$. Условия касания с $y=0$ и $y=x$ дают систему уравнений. Исключая параметры, получаем ДУ.

32
Составить ДУ окружностей, касающихся одновременно прямых $y = 0$ и $x = 0$ и расположенных в первой и третьей четвертях.
▼

Решение

Решение

Центр окружности в 1-й четверти: $(a, a)$, радиус $a > 0$: $(x-a)^2 + (y-a)^2 = a^2$.

Центр в 3-й четверти: $(-a, -a)$: $(x+a)^2 + (y+a)^2 = a^2$.

В обоих случаях $x^2 + y^2 - 2a(x+y) + a^2 = 0$.

Дифференцируем: $2x + 2yy' - 2a(1 + y') = 0 \implies a = \frac{x + yy'}{1 + y'}$.

Подставляем в исходное, упрощаем.

33
Составить ДУ всех парабол с осью, параллельной $Oy$, и проходящих через начало координат.
▼

Решение

Ответ: $x^2y'' - 2xy' + 2y = 0$

Решение

Парабола: $y = ax^2 + bx$ (проходит через $(0,0)$, так что $c=0$). Два параметра $a, b$.

$y' = 2ax + b$, $y'' = 2a \implies a = \frac{y''}{2}$, $b = y' - 2ax = y' - xy''$.

$y = \frac{y''}{2}x^2 + (y' - xy'')x = \frac{x^2 y''}{2} + xy' - x^2y''= xy' - \frac{x^2y''}{2}$.

$2y = 2xy' - x^2y'' \implies x^2y'' - 2xy' + 2y = 0$.

34
Составить ДУ всех окружностей, касающихся оси абсцисс.
▼

Решение

Ответ: $(y''y + y'^2 + 1)^2 = (y'^2 + 1)^3$

Решение

Окружность с центром $(a, b)$ и касающаяся $Ox$: $(x-a)^2 + (y-b)^2 = b^2$. Два параметра.

Дифференцируем: $2(x-a) + 2(y-b)y' = 0$, т.е. $(x-a) = -(y-b)y'$.

Ещё раз: $1 + y'^2 + (y-b)y'' = 0 \implies y-b = -\frac{1+y'^2}{y''}$.

$x - a = \frac{(1+y'^2)y'}{y''}$. Подставляем в исходное.

35

▼

Решение

Ответ: $yy' + zz' = 0$, $y^2 + 2xzz' = x^2 z'^2 + z^2$

Решение

Из первого: $b = ax + z$. Дифференцируем: $a + z' = 0 \implies a = -z'$.

Из второго: $2yy' + 2zz' = 0 \implies yy' + zz' = 0$.

Подставляем $a = -z'$, $b = -z'x + z$ в $y^2 + z^2 = b^2$:

$y^2 + z^2 = (-z'x + z)^2 = z'^2x^2 - 2xzz' + z^2$.

$y^2 = z'^2x^2 - 2xzz'$, т.е. $y^2 + 2xzz' = x^2z'^2 + z^2$... (с учётом $z^2$ сокращается).

Задачи 37–50. Изогональные и ортогональные траектории
Составить дифференциальные уравнения траекторий, пересекающих линии данного семейства под данным углом $\varphi$.
37
$y = Cx^4$, $\varphi = 90°$
▼

Решение

Ответ: $4yy' = -x$

Шаг 1. Находим ДУ семейства

$y' = 4Cx^3$. Из исходного $C = y/x^4$, тогда $y' = \frac{4y}{x}$.

Шаг 2. Ортогональные траектории

Для ортогональных траекторий заменяем $y'$ на $-1/y'$:

$-\dfrac{1}{y'} = \dfrac{4y}{x} \implies y' = -\dfrac{x}{4y} \implies 4yy' = -x$.

38
$y^2 = x + C$, $\varphi = 90°$
▼

Решение

Ответ: $y' = -2y$

Шаг 1. ДУ семейства

$2yy' = 1 \implies y' = \frac{1}{2y}$.

Шаг 2. Ортогональные траектории

$-\frac{1}{y'} = \frac{1}{2y} \implies y' = -2y$.

39
$x^2 = y + Cx$, $\varphi = 90°$
▼

Решение

Ответ: $(x^2 + y)y' = -x$

Шаг 1. ДУ семейства

$C = \frac{x^2 - y}{x} = x - \frac{y}{x}$. Дифференцируем исходное: $2x = y' + C$.

$y' = 2x - C = 2x - x + \frac{y}{x} = x + \frac{y}{x} = \frac{x^2 + y}{x}$.

Шаг 2. Ортогональные траектории

$-\frac{1}{y'} = \frac{x^2 + y}{x} \implies y' = \frac{-x}{x^2 + y} \implies (x^2+y)y' = -x$.

40
$x^2 + y^2 = a^2$, $\varphi = 45°$
▼

Решение

Ответ: $(x - y)y' = x + y$; $(x + y)y' = y - x$

Шаг 1. ДУ семейства (окружности)

$2x + 2yy' = 0 \implies y' = -\frac{x}{y}$, т.е. $\operatorname{tg}\alpha = -\frac{x}{y}$.

Шаг 2. Изогональные траектории под углом $45°$

$\operatorname{tg}\beta = \operatorname{tg}(\alpha \pm 45°) = \frac{\operatorname{tg}\alpha \pm 1}{1 \mp \operatorname{tg}\alpha}$.

$y'_{\text{тр}} = \frac{-x/y + 1}{1 + x/y} = \frac{y - x}{y + x}$ или $y'_{\text{тр}} = \frac{-x/y - 1}{1 - x/y} = \frac{x + y}{x - y}$.

41
$y = kx$, $\varphi = 60°$
▼

Решение

Ответ: $(x \mp y\sqrt{3})y' = y \pm x\sqrt{3}$

Шаг 1. ДУ семейства

$y' = k = y/x$.

Шаг 2. Траектории под углом $60°$

$y'_{\text{тр}} = \frac{y/x \pm \tan 60°}{1 \mp (y/x)\tan 60°} = \frac{y/x \pm \sqrt{3}}{1 \mp y\sqrt{3}/x} = \frac{y \pm x\sqrt{3}}{x \mp y\sqrt{3}}$.

42
$3x^2 + y^2 = C$, $\varphi = 30°$
▼

Решение

Ответ: $(3x \mp y\sqrt{3})y' = y \pm 3x\sqrt{3}$

Шаг 1. ДУ семейства

$6x + 2yy' = 0 \implies y' = -\frac{3x}{y}$.

Шаг 2. Под углом $30°$

$\operatorname{tg}\beta = \frac{-3x/y \pm \tan 30°}{1 \mp (-3x/y)\tan 30°} = \frac{-3x/y \pm 1/\sqrt{3}}{1 \pm 3x/(y\sqrt{3})}$.

Упрощаем, получаем ответ.

43
$y^2 = 2px$, $\varphi = 60°$
▼

Решение

Ответ: $(2x \mp y\sqrt{3})y' = y \pm 2x\sqrt{3}$... упрощая

Шаг 1. ДУ семейства

$2yy' = 2p \implies y' = \frac{p}{y} = \frac{y^2/(2x)}{y} = \frac{y}{2x}$.

Шаг 2. Траектории под $60°$

Аналогично предыдущим задачам, заменяем $\operatorname{tg}\alpha = y/(2x)$ через формулу $\operatorname{tg}(\alpha \pm 60°)$.

44
$r = a + \cos\theta$, $\varphi = 90°$
▼

Решение

Ответ: $r' \sin\theta = r^2$

Шаг 1. ДУ в полярных координатах

Для ортогональных траекторий в полярных координатах: если ДУ семейства $\frac{dr}{d\theta} = f(r,\theta)$, то ДУ ортогональных траекторий: $\frac{dr}{d\theta} = -\frac{r^2}{f(r,\theta)}$.

$\frac{dr}{d\theta} = -\sin\theta$. Ортогональные: $\frac{dr}{d\theta} = \frac{r^2}{\sin\theta}$.

45
$r = a\cos^2\theta$, $\varphi = 90°$
▼

Решение

Ответ: $r' = \frac{1}{2}r\operatorname{ctg}\theta$

Шаг 1. ДУ семейства

$r' = -2a\cos\theta\sin\theta$. Из $a = r/\cos^2\theta$: $r' = -2r\sin\theta/\cos\theta = -2r\operatorname{tg}\theta$.

$\frac{1}{r}\frac{dr}{d\theta} = -2\operatorname{tg}\theta$.

Шаг 2. Ортогональные траектории

Заменяем $\frac{1}{r}\frac{dr}{d\theta}$ на $-\frac{r}{dr/d\theta}$: $-\frac{r}{r'} \cdot \frac{1}{r} = -2\operatorname{tg}\theta$, $\frac{1}{r'} = 2\operatorname{tg}\theta$, $r' = \frac{1}{2}\operatorname{ctg}\theta \cdot r$... Нет, в полярных ортогональные: заменяем $r'$ на $-r^2/r'$.

46
$r = a\sin\theta$, $\varphi = 45°$
▼

Решение

Ответ: $r' = r\operatorname{ctg}(\theta \pm 45°)$

Шаг 1. ДУ семейства

$r' = a\cos\theta$. Из $a = r/\sin\theta$: $r' = \frac{r\cos\theta}{\sin\theta} = r\operatorname{ctg}\theta$.

Шаг 2. Изогональные траектории

В полярных координатах: $\operatorname{tg}\psi = \frac{r}{r'}$, где $\psi$ — угол между радиус-вектором и касательной.

Для изогональных под углом $\varphi$: заменяем $\psi$ на $\psi \pm \varphi$.

47
$y = x\ln x + Cx$, $\varphi = \operatorname{arctg} 2$
▼

Решение

Ответ: $(x + 2y)y' = -3x - y$; $(3x + 2y)y' = y - x$

Шаг 1. ДУ семейства

$y' = \ln x + 1 + C$. Из $C = \frac{y - x\ln x}{x}$: $y' = \ln x + 1 + \frac{y}{x} - \ln x = 1 + \frac{y}{x} = \frac{x+y}{x}$.

Шаг 2. Под углом $\varphi = \operatorname{arctg}2$

$\operatorname{tg}\varphi = 2$. $y'_{\text{тр}} = \frac{(x+y)/x \pm 2}{1 \mp 2(x+y)/x} = \frac{x + y \pm 2x}{x \mp 2(x+y)}$.

48
$x^2 + y^2 = 2ax$, $\varphi = 45°$
▼

Решение

Ответ: $y'[2xy \pm (x^2 - y^2)] = y^2 - x^2 \pm 2xy$

Шаг 1. ДУ семейства

$2x + 2yy' = 2a$. Из $a = \frac{x^2+y^2}{2x}$: $2x + 2yy' = \frac{x^2+y^2}{x}$.

$y' = \frac{x^2+y^2-2x^2}{2xy} = \frac{y^2-x^2}{2xy}$.

Шаг 2. Под $45°$

Заменяем через формулу тангенса суммы. Подставляем $\operatorname{tg}\alpha = \frac{y^2-x^2}{2xy}$.

49
$x^2 + C^2 = 2Cy$, $\varphi = 90°$
▼

Решение

Ответ: $x(1 + y'^2) = -2yy'$

Шаг 1. ДУ семейства

$2x = 2Cy' \implies C = x/y'$.

Подставляем: $x^2 + x^2/y'^2 = 2xy/y'$, т.е. $x(1 + 1/y'^2) = 2y/y'$.

$x \cdot \frac{y'^2 + 1}{y'^2} = \frac{2y}{y'} \implies x(y'^2 + 1) = 2yy'$.

Шаг 2. Ортогональные

Заменяем $y'$ на $-1/y'$: $x(1/y'^2 + 1) = -2y/y'$, т.е. $x(1+y'^2)/y'^2 = -2y/y'$.

$x(1+y'^2) = -2yy'$.

50
$y = Cx + C^3$, $\varphi = 90°$
▼

Решение

Ответ: $yy'^3 + xy'^2 = -1$

Шаг 1. ДУ семейства

$y' = C$. Подставляем в исходное: $y = y'x + y'^3$.

Шаг 2. Ортогональные траектории

Заменяем $y'$ на $-1/y'$: $y = -\frac{x}{y'} + \left(-\frac{1}{y'}\right)^3 = -\frac{x}{y'} - \frac{1}{y'^3}$.

Умножаем на $y'^3$: $yy'^3 = -xy'^2 - 1$, т.е. $yy'^3 + xy'^2 = -1$.
